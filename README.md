# Group1-AIPM — Git 协作实验

本仓库用于组内成员的 **Fork + Pull Request** 协作实验。仓库公开，成员无需被添加为协作者，即可通过 Fork 提交代码，由维护者逐个审查、批准合并。

## 实验任务

每位成员需要完成以下操作：

1. **Fork** 本仓库（打开仓库页面，点击右上角 `Fork`），在自己的账号下得到一份副本。
2. 克隆**自己账号下的 Fork** 到本地。
3. 在本地创建属于自己的分支（建议命名为 `学号`，例如 `18`）。
4. 在分支上**新建一个文件**，文件名使用你的学号，例如 `18.txt`。
5. 该文件**内容只需包含你的两位学号数字**即可，例如：

   ```
   18
   ```

   > 只写数字，不要写姓名、不要写多余文字，方便检查。

6. 提交（commit）并推送到**你自己的 Fork**（push）。
7. 回到原仓库页面，发起 **Pull Request**，请求将你的分支合并进 `main`。
8. 等待维护者审查批准。

## 常用命令

```bash
# 1. 克隆你自己的 Fork（把 <你的用户名> 换成你的 GitHub 用户名）
git clone https://github.com/<你的用户名>/Group1-AIPM.git
cd Group1-AIPM

# 2. 创建并切换到自己的分支
git checkout -b 18

# 3. 新建文件并写入学号（内容为两位数字）
echo "18" > 18.txt

# 4. 查看状态并提交
git add 18.txt
git commit -m "添加学号 18 的文件"

# 5. 推送分支到你的 Fork
git push -u origin 18

# 6. 回到原仓库页面，点击 "New pull request" 发起合并请求
```

## 检查方式

合并完成后，`main` 分支下应存在每位成员以学号命名的文件，且每个文件内容均为对应的两位学号数字。

## 注意事项

- 成员推送的是**自己的 Fork**，不要直接向原仓库推送（也没有权限）。
- 每位成员只负责自己的学号文件，不要修改别人的文件，避免冲突。
- 文件内容只写两位学号数字，不要包含其他信息。
- 示例文件见 `18.txt`（仅作格式示范，请替换为自己的学号）。
- 所有合并请求由维护者在 PR 页面审查批准后合并。
