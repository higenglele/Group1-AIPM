# Group1-AIPM — Git 协作实验

本仓库用于组内成员的 Git 分支与合并实验。

## 实验任务

每位成员需要完成以下操作：

1. 从 `main` 分支创建一个属于自己的分支（建议命名为 `学号`，例如 `18`）。
2. 在自己的分支上**新建一个文件**，文件名使用你的学号，例如 `18.txt`。
3. 该文件**内容只需包含你的两位学号数字**即可，例如：

   ```
   18
   ```

   > 只写数字，不要写姓名、不要写多余文字，方便检查。

4. 提交（commit）并推送到远程仓库（push）。
5. 发起合并请求 / Pull Request，将你的分支合并回 `main`。

## 常用命令

```bash
# 1. 拉取最新代码
git pull

# 2. 创建并切换到自己的分支
git checkout -b 18

# 3. 新建文件并写入学号（内容为两位数字）
echo "18" > 18.txt

# 4. 查看状态并提交
git add 18.txt
git commit -m "添加学号 18 的文件"

# 5. 推送分支到远程
git push -u origin 18

# 6. 回到主分支（合并完成后）
git checkout main
git pull
```

## 检查方式

合并完成后，`main` 分支下应存在每位成员以学号命名的文件，且每个文件内容均为对应的两位学号数字。

## 注意事项

- 每位成员只负责自己的分支和文件，不要修改别人的文件，避免冲突。
- 文件内容只写两位学号数字，不要包含其他信息。
- 示例文件见 `18.txt`（仅作格式示范，请替换为自己的学号）。
